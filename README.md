# Моя бібліотека Python

Це стартовий шаблон головної сторінки для зберігання Python-проєктів.

## Як відкрити
1. Розпакуй ZIP-архів.
2. Відкрий `index.html` у браузері.

## Як додати новий проєкт
1. Поклади файл `.py` у папку `projects`.
2. Додай нову картку в `index.html` за зразком.
3. Вкажи правильний шлях до файлу в посиланні завантаження.

## Важливо
Це початковий шаблон. Повний код репозиторію GitHub і повний код проєкту «Карта місць у класі» ще не імпортовані.
